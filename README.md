# 흥부자 관광버스

갈대밭 사이를 달리는 관광버스 안, 등산복을 차려입은 뽀글머리 아줌마들이 음악에 맞춰 춤추는 3D 공간입니다.
버스 안을 직접 걸어 다니며 아무 자리에 앉거나 통로에서 같이 춤출 수 있고, 역광 속 실루엣 사이에서 엄마를 찾는 미니게임이 들어 있습니다.

설치할 것 없이 브라우저로 열면 바로 실행됩니다. (three.js r128을 CDN으로 불러옵니다.)

## 버스 안 풍경

- **승객:** 통로에서 춤추는 아줌마 2명, 좌석에 앉은 아줌마 1명. 나머지 자리는 접속한 사람들이 채우는 자리입니다.
- **기사님:** 운전석에 상의를 벗은 근육질 20대 기사님이 선글라스를 끼고 앉아 박자에 맞춰 고개를 까딱이며 운전합니다. 드롭·훅 구간이나 흥 폭발 때는 한 손을 들고 같이 흔듭니다.
- **창밖:** 갈대밭이 지평선까지 이어지고, 멀리 안개 낀 숲이 지나갑니다.
- **실내:** 별빛 천장, 미러볼, 커튼, 노래방 TV, 흰 머리받침 커버.

## 조작법

| 동작 | 키보드 | 모바일 |
|---|---|---|
| 걷기 | `W` `A` `S` `D` / 방향키 | 왼쪽 아래 조이스틱 |
| 시점 돌리기 | 마우스 드래그 | 화면 드래그 |
| 확대·축소 | 마우스 휠 | 두 손가락 핀치 |
| 1인칭 / 3인칭 전환 | `V` | 조작판 버튼 |
| 가까운 좌석에 앉기 / 일어나기 | `E` | 조작판 버튼 |
| 춤 동작 | `1` 손가락 하늘 찌르기 · `2` 박수 치며 흔들기 · `3` 만세 손 흔들기 | 조작판 버튼 |
| 흥 폭발 (게이지가 찼을 때) | `Space` | 조작판 버튼 |
| 음악 켜기/끄기 | `M` | 조작판 버튼 |

시작 화면에서 닉네임을 정하면 내 아바타 머리 위에 표시됩니다. 걷다가 멈추면 고른 춤 동작으로 자동으로 춤을 춥니다. 등산복 색과 머리색은 조작판에서 바꿀 수 있습니다.

## 흥 폭발

통로에 서서 **5분 동안 춤을 추면** 흥 게이지가 차고, 그때 한 번 쓸 수 있습니다. 쓰고 나면 게이지가 다시 0부터 찹니다. (걷거나 앉아 있는 동안은 게이지가 차지 않습니다.)

누르면 화면에 **"OOO님이 흥을 폭발시켰습니다!"** 가 뜨고, 16박자 동안 다음 효과가 이어집니다.

- 천장 레이저가 버스 안을 휘젓습니다.
- 박자마다 폭죽이 터지고, 4박자마다 꽃가루가 쏟아집니다.
- 에어혼과 크래시 효과음이 울립니다.
- 화면이 번쩍이고 흔들립니다.
- 승객 모두 만세를 춥니다.

여러 명이 함께 쓰는 공간에서 화면이 너무 정신없어지지 않도록 횟수를 제한한 것입니다.

## 음악

음원 파일 없이 Web Audio API로 실시간 합성하는 오리지널 곡 두 개를 조작판에서 고를 수 있습니다.

- **EDM (128 BPM):** 킥, 클랩, 오프비트 베이스, 슈퍼소 코드, 리드.
- **관광 힙합 (92 BPM):** 스윙 붐뱁 드럼, 808 베이스, 일렉트릭 피아노 재즈 코드, 트로트풍 리드 훅, 브라스 스탭.

두 곡 모두 16마디 단위로 인트로 → 그루브/벌스 → 빌드업 → 드롭/훅이 반복되고, 아바타들의 춤이 박자에 맞춰 움직입니다.

## 엄마 찾기 게임

오른쪽 위 **엄마 찾기 게임** 버튼으로 시작합니다.

1. 좌석에 앉아 있던 엄마를 먼저 보여줍니다. 엄마의 옷 색과 앉은 자리는 매 판 달라집니다.
2. 엄마가 일어나 통로로 나가면, 카메라가 버스 옆으로 빠져 엄마의 위치를 색이 있는 채로 한 번 더 보여줍니다.
3. 해가 기울며 역광이 되고, 모두 실루엣이 됩니다.
4. 아줌마들이 자리를 바꾸며 섞이고 한참 춤을 춥니다.
5. "엄마는 어디 있을까?"가 뜨면 창문 너머의 실루엣을 눌러 고릅니다.

엄마가 들어가는 자리와 섞이는 순서는 매 판 무작위입니다. 처음 두 판은 엄마만 다른 춤을 추는 힌트가 있습니다. 연속으로 맞히면 섞는 횟수가 늘고 빨라집니다. 게임 속 춤추는 아줌마 무리는 게임할 때만 나타납니다.

## 로컬에서 실행

`index.html`을 브라우저로 바로 열어도 되지만, 간단한 로컬 서버로 여는 것을 권장합니다.

```bash
python3 -m http.server 8000
# 그다음 http://localhost:8000 접속
```

## GitHub Pages로 공개하기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 그대로 올립니다.
   ```bash
   git init
   git add .
   git commit -m "흥부자 관광버스"
   git branch -M main
   git remote add origin https://github.com/<내아이디>/<저장소이름>.git
   git push -u origin main
   ```
2. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, 브랜치를 `main` / `/ (root)`로 지정합니다.
3. 1~2분 뒤 `https://<내아이디>.github.io/<저장소이름>/` 주소로 누구나 접속할 수 있습니다.

## 파일 구조

```
index.html      화면 구성 (HUD, 조작판, 시작 화면, 게임 결과 카드)
css/style.css   스타일
js/main.js      3D 장면, 아바타, 기사님, 춤 동작, 음악 합성, 걷기·시점, 흥 폭발, 엄마 찾기 게임
```

`js/main.js` 안에서 손보기 쉬운 곳:

- `LEAD`, `CH`, `BASS` — EDM 멜로디와 코드
- `HH_LEAD`, `HH_CH`, `HH_BASS`, `playStepHH()` — 힙합 트랙
- `HEUNG_NEED` — 흥 폭발에 필요한 춤 시간(초), 기본 300
- `JACKETS`, `HAIRS` — 등산복·머리 색 팔레트
- `computePose()` — 춤 동작 (새 동작을 `case`로 추가)
- `makeDriver()`, `updateDriver()` — 기사님 모습과 동작
- `paintReeds()` — 창밖 갈대밭 그림
- 통로 댄서·좌석 승객 배치 — `// aisle dancers`, `// seated passengers` 주석 아래
- `SLOTS`, `startGame()` — 엄마 찾기 게임의 자리와 난이도

## 참고

- 지금은 각자 자기 브라우저에서 즐기는 구조입니다. 여러 사람이 같은 버스에 동시에 접속해 서로의 아바타와 흥 폭발 알림을 보려면 WebSocket 서버(예: Colyseus, Socket.IO)나 Firebase 같은 실시간 백엔드를 추가해야 합니다.
- 소리는 브라우저 정책상 "탑승하기" 버튼을 누른 뒤부터 납니다.
